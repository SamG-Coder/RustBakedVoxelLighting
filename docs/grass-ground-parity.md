# Grass and ground correction — 31 October 2026

The initial Vulkan pass rendered six species and 1,800 candidate plants per 24-metre page. It also used approximate habitat thresholds, a simple tone curve, and material weights interpolated over the terrain triangles.

The corrected pass imports all twelve names, dimensions and habitat mixtures from the browser's plant catalogue. It uses 3,900 base candidates and 975 independently seeded accents, filtered by the original habitat, root, traffic, slope and shoreline rules. Forest edges, woodland gaps, moisture, flower colonies, dry meadow, bracken and fern redistribution, colour gradients and growth direction now use the source formulas. Native page seeds remain different, so individual plant positions are not identical.

Five reference cases generated by the browser's actual `grassHabitat()` function are checked against the Rust implementation. Density, height, width, colour, flow, woodland weight and all twelve species weights agree within 0.002. Existing generation tests cover bounded geometry, deterministic output, water exclusion and cancellation. Seven workspace tests pass.

Grass lighting now rotates its represented blade normal by the tuft's growth direction. The simplified per-channel tone curve was replaced with the Three.js ACES colour matrices and RRT/ODT fit, with the same 1.05 exposure. Sun diffuse response includes the Lambert 1/pi factor and source 2.6 daytime intensity. This does not substitute for the still-outstanding native voxel GI.

Ground control channels are now separate full-resolution textures sampled per pixel: traffic, root influence, slope, and canopy. A prepared habitat texture supplies woodland weight and geographic colour. Paths use soil; wooded regions blend to litter; slopes blend to stone. Surface UVs account for PNG row direction, and continuous two-sample variation uses explicit unwrapped derivatives to avoid grid boundaries and mip spikes. Soil/stone normal maps add close ground detail. The browser's baked grass-to-ground surface atlas is still outstanding.

GPU grass pages remain bounded at 128 slots. Each reserves a maximum 39,000 vertices and 58,500 indices; the shared arena was sized for that maximum. Jobs remain bounded/cancellable, with one page upload per frame. Increased vegetation coverage and terrain texture sampling have a rendering cost; this change does not claim identical performance to the sparse initial version.

Validation run: `ground-runtime.log`, screenshot `evidence/ground-restored.png`. No Vulkan validation or synchronization errors were reported. The review was interactive and the window/view changed, so its frame timings are not a controlled before/after benchmark.
