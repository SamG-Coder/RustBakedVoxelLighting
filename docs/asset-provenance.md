# Asset provenance

The release world is an export of SamG-Coder/BakedVoxelLighting, an MIT-licensed procedural browser project, at source commit c7ca1495b7e211171cb14921703b150d5b426a92. It contains the generated 4 km by 4 km terrain, ecology, river data and procedural plant meshes. The native importer rebakes impostors and ground-cover atlases from that project. Original generated material prompts are recorded in [asset-prompts.md](asset-prompts.md); that inventory describes the initial source materials, not every subsequent atlas or variant.

These are the author's generated woodland assets, not extracted Kingdom Come game content. Native bake/export tools are in tools/. Asset output is distributed with the Windows release and downloaded by tools/fetch-assets.ps1 for source builds, rather than stored in Git history.
